# BKマネージャー 事業計画シミュレーター

物件王「260708_事業計画検討書【雛型】」のExcel数式を解析し、加盟店様がブラウザ上で入力すると
その場で事業計画書（損益分岐点・年次P&L・目標契約件数・決定事項サマリー等）が自動生成されるWebアプリです。

## 使い方

1. `index.html` をブラウザで直接開くだけで動作します（サーバー不要）。
   - 二重クリックで開く、または簡易サーバーを立てて開いてください：
     ```bash
     cd bk-business-plan-simulator
     python3 -m http.server 8000
     # ブラウザで http://localhost:8000 を開く
     ```
2. 「①事業計画入力」で8ステップのウィザードに入力（自動的にブラウザのlocalStorageへ保存されます）。
3. 「②事業計画書」で完成した計画書を確認し、右上の「🖨 印刷 / PDFとして保存」から
   ブラウザの印刷ダイアログ（A4 / 「PDFとして保存」）で出力できます。
4. 「給与整合性チェック」「インセンティブ試算」「スタッフ能力評価」は、人員体制で入力した
   スタッフ情報と連動する補助ツールです。

## ファイル構成

```
index.html
css/style.css       画面用スタイル（信頼感のあるネイビー×ゴールドのトーン）
css/print.css       印刷・PDF用スタイル
js/defaults.js      初期値・能力判定マスタ
js/calc.js          目標設定／ターゲットエリア／事業検討／PL(1・2年目)の計算エンジン
js/schedule.js      全体フロー（研修①〜⑨）の逆算ロジック
js/content.js       研修詳細・店舗内装の固定コンテンツ
js/state.js         localStorage永続化
js/salary.js        給与整合性チェックの計算
js/incentive.js     インセンティブ試算の計算
js/skill.js         スタッフ能力評価（能力判定）の計算
js/ui-*.js          画面描画
```

## 元Excelからの主な設計判断（ご確認事項）

開発時にオーナー様と協議し、以下の方針で実装しています。

1. **全体フローのスケジュール逆算**：元シートは数式を持たない静的なガントチャート（図形のみ）
   だったため、営業日ベース（水曜定休想定・約120営業日）の近似計算で研修①〜⑨の日程を
   オープン予定日から逆算表示しています。実際の日程は物件王担当者と調整してください。
2. **店舗内装の必要面積**：編集可能にしています（デフォルト値はExcelと同じ）。
3. **給与整合性／インセンティブ検討／能力判定**：ご依頼どおりフル実装していますが、
   元シートが店長1名＋エージェント3名＋サポート2名の固定6枠構成だったのに対し、
   本アプリは人数を可変にしているため、「予想売上より鑑みる適正水準イメージ」の配分は
   役職ティア単位（店長／エージェント／サポート）で元シートの配点比率合計を
   維持しつつ人数按分する一般化を行っています。
4. **インセンティブ検討シートの経過月数**：元シートは参照セル（V列）が空実装のまま
   放置されていたため、入社日・基準日から算出する意図を汲んで実装補完しています。
5. **建築シナジー事業のCOGS計上**：元Excelの仕様どおり、収益は月割りの平準化額で計上する一方、
   原価は発生月に単発フルコストで計上するため、大型契約が計上される月（1年目12月など）は
   一時的に大きな赤字が出ます。これは元シートの仕様を忠実に再現した結果です。

すべての数式はExcel原本のセル参照をもとに翻訳しており、勝手な簡略化はしていません
（詳細はソースコード内のコメントを参照してください）。
