# クラウド保存の設定手順（Googleスプレッドシート + Apps Script）

この手順は一度だけ行えば、以降は事業計画シミュレーターの「☁ 保存してURL発行」ボタンから
会社ごとのデータをスプレッドシートに保存できるようになります。

Googleアカウントでのログイン・スクリプトの承認は、ご自身（物件王担当者）の操作が必要です
（AIが代わりに行うことはできません）。所要時間は5分程度です。

## 手順

1. **新しいGoogleスプレッドシートを作成**
   - https://sheets.google.com を開き、「空白のスプレッドシート」を作成
   - タイトルを「事業計画シミュレーター_管理台帳」など分かりやすい名前に変更

2. **Apps Scriptエディタを開く**
   - メニューの「拡張機能」→「Apps Script」をクリック

3. **コードを貼り付け**
   - エディタ内のデフォルトコード（`function myFunction() {...}`）を全て削除
   - 同じフォルダにある `Code.gs` の中身を全てコピーして貼り付け
   - 上部の「プロジェクト名」を「事業計画シミュレーター保存API」などに変更して保存（Ctrl+S / Cmd+S）

4. **ウェブアプリとしてデプロイ**
   - 右上の「デプロイ」→「新しいデプロイ」をクリック
   - 「種類の選択」の歯車アイコン →「ウェブアプリ」を選択
   - 「次のユーザーとして実行」：**自分**
   - 「アクセスできるユーザー」：**全員**
   - 「デプロイ」をクリック
   - 初回は「承認が必要です」と表示されるので、ご自身のGoogleアカウントで承認してください
     （「このアプリは Google で確認されていません」という警告が出た場合は、「詳細」→
     「（プロジェクト名）に移動（安全ではないページ）」を選べば進めます。自分で作成した
     スクリプトなので問題ありません）
   - デプロイ完了後に表示される **ウェブアプリのURL**（`https://script.google.com/macros/s/.../exec` の形式）
     をコピーしてください

5. **URLをアプリに設定**
   - コピーしたURLを、シミュレーターアプリの「クラウド保存の設定」画面に貼り付けて保存してください
   - これで「☁ 保存してURL発行」ボタンから、このスプレッドシートにデータが保存されるようになります

## スプレッドシートでの管理

- 保存したデータは自動的に「companies」というシート（タブ）に1社1行で追加されます
  （デフォルトの「シート1」ではなく、下部のタブに新しく追加されるのでご注意ください）
- 列：id / 会社名 / **共有URL**（クリックすると「開く」リンクからその会社のページへ直接ジャンプできます）／
  作成日時 / 更新日時 / オープン予定日 / 1年目営業損益 / 2年目営業損益 / データ(JSON)
- 「データ(JSON)」列は人が読むための列ではないため、初期状態で折りたたんで非表示にしています
  （見たい場合は列の境目の「▶」をクリックすると展開できます）
- 見出し行は太字・色付けで固定表示されます

## 再デプロイ時の注意（コードを更新した場合）

Code.gsの内容を後から更新した場合は、「デプロイ」→「デプロイを管理」→ 該当のデプロイの
鉛筆アイコン →「バージョン」で「新バージョン」を選んで「デプロイ」を押してください
（URLは変わりません）。「新しいデプロイ」を選ぶと別のURLが発行されてしまうのでご注意ください。

コード上部の `APP_BASE_URL`（アプリの公開URL）は、GitHub PagesのURLを変更した場合はここも
合わせて書き換えて再デプロイしてください。そうしないと、スプレッドシートの「共有URL」列の
リンク先が古いURLのままになります。

### 見た目の体裁（列幅・色・非表示など）を後から整えたい場合

体裁の設定は「companies」タブが**新規作成される時だけ**自動で適用されますが、既にデータが
入っている既存のシートに対しても、データを消さずに体裁だけ整え直せるメニューを用意しています。

1. 上記「再デプロイ時の注意」の手順で、最新の `Code.gs` を貼り直して再デプロイしておく
2. スプレッドシートの画面を開き直す（再読み込み。すでに開いている場合はブラウザの更新ボタン）
3. 上部メニューに **「事業計画シミュレーター」** が追加されるので、クリック→
   **「スプレッドシートの体裁を整える」** を選択
4. 「体裁を整えました」と表示されれば完了です

旧いレイアウト（共有URL列がまだ無い状態）で保存済みのデータがあっても、自動的に列を挿入して
新しいレイアウトへ移行し、共有URLも既存の行に補完されます。

## セキュリティについて

このAPIは手軽に使えるよう「URL（id）を知っていれば誰でも読み書きできる」設計です
（Googleログイン不要）。IDは推測困難なランダム文字列で発行されますが、発行したURLは
社外・無関係な方に共有しないようご注意ください。よりアクセス制御を厳しくしたい場合は、
今後の拡張（社内限定認証の追加など）についてご相談ください。

# 会社別スプレッドシートの自動作成（SheetFactory.gs）

事業計画書の「📁 会社フォルダを作ってスプレッドシートを作成」ボタンを使えるようにする設定です。
一度だけ、管理者（Googleドライブの持ち主）が行います。上の「クラウド保存」とは**別のプロジェクト**です。

## できあがるドライブの構成

```
事業計画書／               ← 管理者用の親フォルダ（自動で作成）
 ├ 〇〇不動産／             ← 会社ごとのフォルダ（会社名から「株式会社」等を除いた名前）
 │   └ 〇〇不動産_事業計画  ← 雛型のコピー（社名・連動データ入り）
 └ △△ホーム／
     └ △△ホーム_事業計画
```

## 手順

1. https://script.google.com を開き、「新しいプロジェクト」を作成（名前：「事業計画シミュレーター_スプレッドシート作成」など）
2. 初期コードを削除し、`SheetFactory.gs` の中身を全て貼り付けて保存
3. 必要なら冒頭の設定を変更
   - `ROOT_FOLDER_ID`：親フォルダを共有ドライブなど特定の場所に置きたい時だけ、フォルダIDを入れる（空ならマイドライブ直下に「事業計画書」を作成）
   - `ACCESS_KEY`：合言葉。設定すると、アプリ側にも同じ合言葉を入力した人だけが使える（推奨）
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**／アクセスできるユーザー：**全員**
   - 初回は承認画面が出ます（Googleドライブとスプレッドシートの操作許可）。「詳細」→「（プロジェクト名）に移動」で進めます
5. 表示された **ウェブアプリのURL** をコピー
6. 事業計画書の「詳細資料（スプレッドシート）」→「自動作成の連携設定」にURL（と合言葉）を入力して保存
   - 全員に同じ設定を配りたい場合は、`js/sheet-link.js` の `SHEET_FACTORY_URL` にURLを書いて再デプロイしてください（合言葉は各自が入力）

## 使い方

- 会社名を入力 → 事業計画書の最下部で「📁 会社フォルダを作ってスプレッドシートを作成」を押す
- 同じ会社でもう一度押しても、同名のファイルがあれば新しく作らず既存のものを開きます
- 数字を変えたら「🔄 連動データを最新に更新」で、スプレッドシート側にも反映できます

雛型を差し替えた場合は、`TEMPLATE_ID` を新しい雛型のIDに書き換えてください。

## 作成したスプレッドシートの保護（編集ロック）

作成・更新のたびに、次のとおり保護がかかります。

| 対象 | 状態 |
|---|---|
| 数式のセル、率・基準値などの設定値（労働分配率、足切り係数、ランク判定の比率など） | **ロック**（作成者以外は編集不可） |
| 連動データ シート | **ロック**（ただし B25「インセンティブ原資」だけは手入力できる） |
| 名前・日付・評価・チェック・コメントなどの入力欄 | 編集できる |
| 共有設定 | 編集者は他の人の追加・権限変更ができない |

- ロックを外せるのは、スクリプトを実行しているアカウント（作成者）だけです。
- 「🔄 連動データを最新に更新」を押すと、連動データだけを書き換えます（B25 の手入力値は残ります）。保護は付け直されます。
- スクリプトを更新したときは、「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「バージョン：新バージョン」→「デプロイ」で、**同じURLのまま**反映してください。初回は追加の承認画面が出ます。
